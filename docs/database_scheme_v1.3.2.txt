Ringkasan Pembetulan v1.3.2
special_room_allocation_slots (Isu Kritikal): Kekangan UNIQUE (special_room_allocation_id) dibuang dan digantikan dengan slot_sequence IN (1, 2, 3), UNIQUE (special_room_allocation_id, slot_sequence), serta UNIQUE (special_room_allocation_id, start_minute, end_minute). timetable_entry_id dan day_of_week diikat pada special_room_allocations dan dipropagasikan melalui Composite FK ke semua slot supaya Single = 1 slot, Double = 2 slot, Triple = 3 slot menggunakan room_id, timetable_entry_id, dan allocation_date yang sama, mewakili period sebenar dalam timetable_entry_target_periods, serta menyemak kapasiti max_concurrent_classes mengikut pertindihan masa sebenar setiap slot.
absence_reasons (Jadual Baharu — Jadual #36 daripada 42): Ditambah jadual absence_reasons (id, name, description, is_active, created_at, updated_at) dan dihubungkan daripada teacher_absences.absence_reason_id melalui FOREIGN KEY (absence_reason_id) REFERENCES absence_reasons(id) ON DELETE RESTRICT, ditambah trigger menghalang sebab tidak aktif (is_active = 0) dipilih bagi rekod baharu sambil mengekalkan rekod sejarah sedia ada.
timetable_workspace_autosaves Foreign Key: Dipisahkan kepada FOREIGN KEY (session_id, academic_year_id) REFERENCES school_sessions(id, academic_year_id) ON DELETE CASCADE dan FK kolum tunggal FOREIGN KEY (base_timetable_version_id) REFERENCES timetable_versions(id) ON DELETE SET NULL, disokong oleh trigger trg_twa_base_version_ins/upd yang menyemak kesepadanan academic_year_id dan session_id. Pemadaman timetable_versions kini menetapkan hanya base_timetable_version_id = NULL tanpa melanggar NOT NULL pada academic_year_id dan session_id.
Excel Import Scope (import_batches.entity_scope): Nilai 'TEACHER_SUBJECTS' digugurkan. Hanya 5 kategori asal yang diluluskan dikekalkan: TEACHERS, SUBJECTS, CLASSES, ROOMS, dan TEACHING_ASSIGNMENTS.
ERD Mermaid Lengkap: Bahagian 7G dikemas kini dengan kod Mermaid erDiagram sebenar yang merangkumi kesemua 42 jadual tanpa sebarang placeholder.
1. SPECIAL ROOM ALLOCATION SLOTS — PEMBETULAN SINGLE, DOUBLE & TRIPLE
Masalah dalam v1.3.1
Kekangan UNIQUE (special_room_allocation_id) pada special_room_allocation_slots mengehadkan setiap special_room_allocation kepada maksimum 1 baris slot sahaja, yang bercanggah dengan keperluan blok Double (2 period) dan Triple (3 period).
Reka Bentuk Baharu v1.3.2
Pengikatan Entry & Hari pada special_room_allocations:
Ditambah timetable_entry_id dan day_of_week dengan FOREIGN KEY (timetable_entry_id, timetable_version_id, timetable_lesson_id, day_of_week) REFERENCES timetable_entries(id, timetable_version_id, timetable_lesson_id, day_of_week) ON DELETE CASCADE.
Indeks unik komposit UNIQUE (id, special_room_schedule_id, timetable_version_id, timetable_lesson_id, timetable_entry_id, room_id, allocation_date, day_of_week) menjadi sasaran Composite FK daripada special_room_allocation_slots.
Jaminan struktur: Semua 1/2/3 slot bagi satu special_room_allocation_id mustahil berbeza room_id, timetable_entry_id, timetable_lesson_id, allocation_date, atau day_of_week.
Struktur Multi-Slot pada special_room_allocation_slots:
Ditambah slot_sequence INTEGER NOT NULL CHECK (slot_sequence IN (1, 2, 3)).
Digantikan UNIQUE (special_room_allocation_id) dengan:
UNIQUE (special_room_allocation_id, slot_sequence)
UNIQUE (special_room_allocation_id, start_minute, end_minute)
Maka:
Single (periods_used = 1): 1 baris (slot_sequence = 1).
Double (periods_used = 2): 2 baris (slot_sequence = 1, 2).
Triple (periods_used = 3): 3 baris (slot_sequence = 1, 2, 3).
Pengesahan Period Sebenar & Keselanjaran (trg_sras_validate_ins/upd):
Trigger memastikan NEW.slot_sequence <= sra.periods_used.
Trigger memastikan wujud padanan tepat dalam timetable_entry_target_periods:
tetp.timetable_entry_id = NEW.timetable_entry_id AND tetp.period_sequence = NEW.slot_sequence AND tetp.start_minute = NEW.start_minute AND tetp.end_minute = NEW.end_minute.
Ini menjamin setiap slot mewakili period 'teaching' sebenar daripada jadual loceng kelas (serta serasi untuk Single Class mahupun Combined Class berbeza jadual loceng apabila julat [start_minute, end_minute) sama).
Trigger memastikan slot bersebelahan (slot_sequence 1↔2↔3) bersambung tepat (prev.end_minute = next.start_minute) tanpa jurang atau pertindihan dalaman.
Pengiraan max_concurrent_classes per Slot (trg_sras_max_concurrent_ins/upd):
Menyemak bilangan kelas unik (COUNT(DISTINCT tlt.class_id)) pada setiap titik permulaan slot bertindih (s.start_minute <= pt.start_minute AND pt.start_minute < s.end_minute) bagi (special_room_schedule_id, room_id, allocation_date).
Jika satu kelas mempunyai blok Triple (P1+P2+P3) dan satu lagi kelas berkongsi bilik sama hanya pada P3, pertindihan hanya berlaku pada P3 (2 <= max_concurrent_classes), manakala slot P1 dan P2 kekal mempunyai kapasiti bebas untuk kelas lain.
Jumlah Slot = periods_used:
SQLite menguatkuasakan had atas (slot_sequence <= periods_used, unik per slot_sequence dan masa), manakala Lapisan Perkhidmatan mengesahkan kelengkapan penuh (COUNT(*) = periods_used) sebelum COMMIT dalam transaksi atomik penyimpanan pelan bilik khas.
2. absence_reasons — PENGURUSAN SEBAB KETIDAKHADIRAN & PERLINDUNGAN SEJARAH
Struktur absence_reasons (Jadual #36)
SQL
CREATE TABLE absence_reasons (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    description TEXT,
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);
CREATE UNIQUE INDEX uq_absence_reasons_name ON absence_reasons (TRIM(name) COLLATE NOCASE);
Integrasi dengan teacher_absences (Jadual #37)
teacher_absences menggunakan absence_reason_id INTEGER NOT NULL (menggantikan reason TEXT sahaja) serta mengekalkan notes TEXT bagi catatan tambahan opsional:
FOREIGN KEY (absence_reason_id) REFERENCES absence_reasons(id) ON DELETE RESTRICT
Tambah sebab baharu: INSERT INTO absence_reasons (name, description) ... (unik tanpa mengira huruf besar/kecil atau ruang tepi).
Ubah nama sebab: UPDATE absence_reasons SET name = ... WHERE id = ... dibenarkan; semua teacher_absences sedia ada kekal sah.
Nyahaktifkan sebab (is_active = 0): Rekod sejarah teacher_absences yang sedia merujuk absence_reason_id tersebut tidak terjejas dan masih boleh dilihat serta dipautkan kepada relief_assignments. Trigger trg_teacher_absences_reason_active_ins/upd hanya menyekat pemilihan sebab is_active = 0 bagi rekod ketidakhadiran baharu atau penukaran kepada sebab tidak aktif.
Halangan pemadaman fizikal: ON DELETE RESTRICT menolak sebarang cubaan DELETE FROM absence_reasons jika id tersebut pernah digunakan dalam teacher_absences (hanya sebab yang belum pernah digunakan boleh dipadam secara fizikal).
3. timetable_workspace_autosaves — PEMBETULAN FOREIGN KEY
Punca Ralat dalam v1.3.1
Dalam v1.3.1, FOREIGN KEY (base_timetable_version_id, academic_year_id, session_id) REFERENCES timetable_versions(id, academic_year_id, session_id) ON DELETE SET NULL cuba menetapkan ketiga-tiga kolum kepada NULL apabila baris timetable_versions dipadamkan, yang akan gagal kerana academic_year_id dan session_id ialah NOT NULL.
Pembetulan v1.3.2
academic_year_id dan session_id kekal NOT NULL dengan:
FOREIGN KEY (session_id, academic_year_id) REFERENCES school_sessions(id, academic_year_id) ON DELETE CASCADE
base_timetable_version_id ialah kolum boleh-NULL dengan FK kolum tunggal:
FOREIGN KEY (base_timetable_version_id) REFERENCES timetable_versions(id) ON DELETE SET NULL
Trigger trg_twa_base_version_ins dan trg_twa_base_version_upd mengesahkan bahawa apabila base_timetable_version_id IS NOT NULL, versi asas tersebut mesti tergolong dalam academic_year_id dan session_id yang sama.
Kesan apabila versi dipadamkan: Jika timetable_version yang tidak dikunci RELIEF dipadamkan, SQLite menetapkan hanya base_timetable_version_id = NULL. academic_year_id, session_id, dan payload_json kekal utuh sepenuhnya supaya draf AUTOSAVE masih boleh dipulihkan dengan selamat dan disimpan sebagai versi baharu.

TEACHERS
SUBJECTS
CLASSES
ROOMS
TEACHING_ASSIGNMENTS
Memasukkan 'TEACHER_SUBJECTS' dalam import_batches.entity_scope merupakan penambahan skop luar spesifikasi dan telah dibuang dalam v1.3.2:
SQL
entity_scope TEXT NOT NULL CHECK (
    entity_scope IN ('TEACHERS', 'SUBJECTS', 'CLASSES', 'ROOMS', 'TEACHING_ASSIGNMENTS')
)
Nota: Ketika mengimport TEACHING_ASSIGNMENTS, Lapisan Perkhidmatan tetap mengesahkan bahawa guru (dikenal pasti melalui short_name) telah dipetakan ke teacher_sessions dan teacher_subjects yang sepadan (selari dengan Composite FK pada teaching_assignment_teachers).
5. KEKANGAN TERAS LAIN YANG DIKEKALKAN DARIPADA v1.3 & v1.3.1
Semua ketetapan terdahulu dikekalkan tanpa perubahan:
School Week Group A/B: school_profile.school_week_group IN ('A', 'B') DEFAULT 'B' terpakai untuk semua tahun/sesi; operating_days (1..7) autoritatif per sesi; WEEKLY dan FORTNIGHTLY ikut sempadan minggu kalendar sekolah (Ahad–Sabtu bagi A, Isnin–Ahad bagi B; bukan rolling 14 hari); MONTHLY ikut bulan kalendar sebenar (YYYY-MM).
Room Configuration Check: CHECK kalis logik 3-nilai NULL dalam teaching_assignments dan timetable_lessons, serta trigger memastikan room_type = 'SPECIAL'.
Time-Off Integrity: Composite FK pada teacher_time_off dan class_time_off + FK tunggal ON DELETE SET NULL pada bell_period_id + trigger sesi/jadual loceng/minit pada kesemua 4 jadual time-off.
Combined Class Teaching & timetable_entry_target_periods: Menyokong Single/Double/Triple gabungan berlainan jadual loceng selagi [start_minute, end_minute) tepat sama dan semua period bertipe 'teaching'.
RELIEF Version Locking: Hanya baris relief_assignments (termasuk status 'CANCELLED') mengunci kekal timetable_versions dan 5 jadual anaknya; relief_batches kosong tidak mengunci versi; pemadaman relief_assignments dan mutasi snapshot sejarah disekat.
Teacher Sessions Validation: DB menjamin <= 1 sesi per guru per tahun akademik (UNIQUE(academic_year_id, teacher_id)), manakala Lapisan Perkhidmatan membuat pre-flight validation == 1 sesi aktif sebelum Main Timetable Solver, import Excel TEACHING_ASSIGNMENTS, dan pemprosesan RELIEF.

PRAGMA foreign_keys = ON;

-- 1. school_profile
CREATE TABLE school_profile (
    id INTEGER PRIMARY KEY CHECK (id = 1),
    school_name TEXT NOT NULL CHECK (LENGTH(TRIM(school_name)) > 0),
    school_code TEXT NOT NULL CHECK (LENGTH(TRIM(school_code)) > 0),
    school_week_group TEXT NOT NULL DEFAULT 'B' CHECK (school_week_group IN ('A', 'B')),
    address TEXT,
    phone TEXT,
    email TEXT,
    principal_name TEXT,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);

-- 2. academic_years
CREATE TABLE academic_years (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    year_code TEXT NOT NULL CHECK (LENGTH(TRIM(year_code)) > 0),
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    start_date TEXT NOT NULL CHECK (start_date GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]'),
    end_date TEXT NOT NULL CHECK (end_date GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]'),
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    CHECK (end_date >= start_date)
);
CREATE UNIQUE INDEX uq_academic_years_code ON academic_years (TRIM(year_code) COLLATE NOCASE);

-- 3. school_sessions
CREATE TABLE school_sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    academic_year_id INTEGER NOT NULL,
    session_code TEXT NOT NULL CHECK (LENGTH(TRIM(session_code)) > 0),
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    sort_order INTEGER NOT NULL DEFAULT 1 CHECK (sort_order >= 1),
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (academic_year_id) REFERENCES academic_years(id) ON DELETE CASCADE,
    UNIQUE (id, academic_year_id)
);
CREATE UNIQUE INDEX uq_school_sessions_code ON school_sessions (academic_year_id, TRIM(session_code) COLLATE NOCASE);

-- 4. operating_days
CREATE TABLE operating_days (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL,
    day_of_week INTEGER NOT NULL CHECK (day_of_week BETWEEN 1 AND 7),
    is_operating INTEGER NOT NULL DEFAULT 1 CHECK (is_operating IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id) REFERENCES school_sessions(id) ON DELETE CASCADE,
    UNIQUE (session_id, day_of_week)
);

-- 5. school_holidays
CREATE TABLE school_holidays (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    academic_year_id INTEGER NOT NULL,
    session_id INTEGER,
    holiday_date TEXT NOT NULL CHECK (holiday_date GLOB '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]'),
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    holiday_type TEXT NOT NULL DEFAULT 'PUBLIC' CHECK (holiday_type IN ('PUBLIC', 'SCHOOL', 'EVENT')),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (academic_year_id) REFERENCES academic_years(id) ON DELETE CASCADE,
    FOREIGN KEY (session_id) REFERENCES school_sessions(id) ON DELETE CASCADE
);
CREATE UNIQUE INDEX uq_school_holidays_year_wide
    ON school_holidays (academic_year_id, holiday_date)
    WHERE session_id IS NULL;
CREATE UNIQUE INDEX uq_school_holidays_session
    ON school_holidays (academic_year_id, session_id, holiday_date)
    WHERE session_id IS NOT NULL;

-- 6. education_levels
CREATE TABLE education_levels (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    academic_year_id INTEGER NOT NULL,
    session_id INTEGER NOT NULL,
    level_code TEXT NOT NULL CHECK (LENGTH(TRIM(level_code)) > 0),
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    sort_order INTEGER NOT NULL DEFAULT 1 CHECK (sort_order >= 1),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id, academic_year_id) REFERENCES school_sessions(id, academic_year_id) ON DELETE CASCADE,
    UNIQUE (id, session_id),
    UNIQUE (id, academic_year_id, session_id)
);
CREATE UNIQUE INDEX uq_education_levels_code ON education_levels (session_id, TRIM(level_code) COLLATE NOCASE);

-- 7. bell_schedules
CREATE TABLE bell_schedules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL,
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    is_default INTEGER NOT NULL DEFAULT 0 CHECK (is_default IN (0, 1)),
    description TEXT,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id) REFERENCES school_sessions(id) ON DELETE CASCADE,
    UNIQUE (id, session_id)
);
CREATE UNIQUE INDEX uq_bell_schedules_name ON bell_schedules (session_id, TRIM(name) COLLATE NOCASE);
CREATE UNIQUE INDEX uq_bell_schedules_default ON bell_schedules (session_id) WHERE is_default = 1;

-- 8. bell_periods
CREATE TABLE bell_periods (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    bell_schedule_id INTEGER NOT NULL,
    period_number INTEGER NOT NULL CHECK (period_number >= 1),
    label TEXT NOT NULL CHECK (LENGTH(TRIM(label)) > 0),
    period_type TEXT NOT NULL CHECK (period_type IN ('teaching', 'recess', 'assembly', 'activity', 'other')),
    start_minute INTEGER NOT NULL CHECK (start_minute BETWEEN 0 AND 1439),
    end_minute INTEGER NOT NULL CHECK (end_minute BETWEEN 1 AND 1440),
    is_schedulable INTEGER NOT NULL DEFAULT 1 CHECK (is_schedulable IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (bell_schedule_id) REFERENCES bell_schedules(id) ON DELETE CASCADE,
    UNIQUE (id, bell_schedule_id),
    UNIQUE (bell_schedule_id, period_number),
    CHECK (end_minute > start_minute),
    CHECK (
        (period_type = 'teaching' AND is_schedulable IN (0, 1))
        OR
        (period_type != 'teaching' AND is_schedulable = 0)
    )
);

-- 9. bell_schedule_level_mappings
CREATE TABLE bell_schedule_level_mappings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL,
    education_level_id INTEGER NOT NULL,
    bell_schedule_id INTEGER NOT NULL,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (education_level_id, session_id) REFERENCES education_levels(id, session_id) ON DELETE CASCADE,
    FOREIGN KEY (bell_schedule_id, session_id) REFERENCES bell_schedules(id, session_id) ON DELETE CASCADE,
    UNIQUE (session_id, education_level_id)
);

-- 10. bell_schedule_day_overrides
CREATE TABLE bell_schedule_day_overrides (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL,
    education_level_id INTEGER,
    day_of_week INTEGER NOT NULL CHECK (day_of_week BETWEEN 1 AND 7),
    bell_schedule_id INTEGER NOT NULL,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id) REFERENCES school_sessions(id) ON DELETE CASCADE,
    FOREIGN KEY (education_level_id) REFERENCES education_levels(id) ON DELETE CASCADE,
    FOREIGN KEY (bell_schedule_id, session_id) REFERENCES bell_schedules(id, session_id) ON DELETE CASCADE
);
CREATE UNIQUE INDEX uq_bs_day_override_session
    ON bell_schedule_day_overrides (session_id, day_of_week)
    WHERE education_level_id IS NULL;
CREATE UNIQUE INDEX uq_bs_day_override_level
    ON bell_schedule_day_overrides (session_id, education_level_id, day_of_week)
    WHERE education_level_id IS NOT NULL;

-- 11. teachers
CREATE TABLE teachers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    short_name TEXT NOT NULL CHECK (LENGTH(TRIM(short_name)) > 0),
    full_name TEXT NOT NULL CHECK (LENGTH(TRIM(full_name)) > 0),
    staff_code TEXT,
    email TEXT,
    phone TEXT,
    max_periods_per_day INTEGER CHECK (max_periods_per_day IS NULL OR max_periods_per_day >= 1),
    max_periods_per_week INTEGER CHECK (max_periods_per_week IS NULL OR max_periods_per_week >= 1),
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    notes TEXT,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);
CREATE UNIQUE INDEX uq_teachers_short_name ON teachers (TRIM(short_name) COLLATE NOCASE);
CREATE UNIQUE INDEX uq_teachers_staff_code
    ON teachers (TRIM(staff_code) COLLATE NOCASE)
    WHERE staff_code IS NOT NULL AND LENGTH(TRIM(staff_code)) > 0;

-- 12. teacher_sessions
CREATE TABLE teacher_sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    academic_year_id INTEGER NOT NULL,
    teacher_id INTEGER NOT NULL,
    session_id INTEGER NOT NULL,
    max_periods_per_day_override INTEGER CHECK (max_periods_per_day_override IS NULL OR max_periods_per_day_override >= 1),
    max_periods_per_week_override INTEGER CHECK (max_periods_per_week_override IS NULL OR max_periods_per_week_override >= 1),
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id, academic_year_id) REFERENCES school_sessions(id, academic_year_id) ON DELETE CASCADE,
    FOREIGN KEY (teacher_id) REFERENCES teachers(id) ON DELETE CASCADE,
    UNIQUE (academic_year_id, teacher_id),
    UNIQUE (academic_year_id, teacher_id, session_id)
);

-- 13. subjects
CREATE TABLE subjects (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    short_name TEXT NOT NULL CHECK (LENGTH(TRIM(short_name)) > 0),
    name TEXT NOT NULL CHECK (LENGTH(TRIM(name)) > 0),
    color_hex TEXT CHECK (color_hex IS NULL OR color_hex GLOB '#[0-9A-Fa-f][0-9A-Fa-f][0-9A-Fa-f][0-9A-Fa-f][0-9A-Fa-f][0-9A-Fa-f]'),

-- 22. teaching_assignments
CREATE TABLE teaching_assignments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    academic_year_id INTEGER NOT NULL,
    session_id INTEGER NOT NULL,
    subject_id INTEGER NOT NULL,
    assignment_type TEXT NOT NULL DEFAULT 'SINGLE' CHECK (assignment_type IN ('SINGLE', 'COMBINED')),
    combined_group_code TEXT,
    lessons_per_week INTEGER NOT NULL CHECK (lessons_per_week BETWEEN 1 AND 5),
    periods_per_lesson INTEGER NOT NULL CHECK (periods_per_lesson IN (1, 2, 3)),
    room_id INTEGER,
    room_periods_per_cycle INTEGER,
    room_frequency TEXT,
    is_active INTEGER NOT NULL DEFAULT 1 CHECK (is_active IN (0, 1)),
    notes TEXT,
    created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    updated_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
    FOREIGN KEY (session_id, academic_year_id) REFERENCES school_sessions(id, academic_year_id) ON DELETE CASCADE,
    FOREIGN KEY (subject_id) REFERENCES subjects(id) ON DELETE RESTRICT,
    FOREIGN KEY (room_id) REFERENCES rooms(id) ON DELETE RESTRICT,
    UNIQUE (id, academic_year_id, session_id),
    UNIQUE (id, academic_year_id, session_id, subject_id),
    CHECK (
        (assignment_type = 'SINGLE' AND combined_group_code IS NULL)
        OR
        (assignment_type = 'COMBINED' AND combined_group_code IS NOT NULL AND LENGTH(TRIM(combined_group_code)) > 0)
    ),
    CHECK (
        (
            room_id IS NULL
            AND room_periods_per_cycle IS NULL
            AND room_frequency IS NULL
        )
        OR
        (
            room_id IS NOT NULL
            AND room_periods_per_cycle IS NOT NULL
            AND room_frequency IS NOT NULL
            AND room_frequency IN ('WEEKLY', 'FORTNIGHTLY', 'MONTHLY')
            AND room_periods_per_cycle > 0
            AND room_periods_per_cycle % periods_per_lesson = 0
            AND (
                room_frequency != 'WEEKLY'
                OR room_periods_per_cycle <= (lessons_per_week * periods_per_lesson)
            )
        )
    )
);
CREATE UNIQUE INDEX uq_ta_combined_code
    ON teaching_assignments (academic_year_id, session_id, TRIM(combined_group_code) COLLATE NOCASE)
    WHERE combined_group_code IS NOT NULL;

CREATE TRIGGER trg_bell_periods_no_overlap_ins
BEFORE INSERT ON bell_periods
BEGIN
    SELECT RAISE(ABORT, 'Bell period overlaps with existing period in the same schedule')
    WHERE EXISTS (
        SELECT 1 FROM bell_periods bp
        WHERE bp.bell_schedule_id = NEW.bell_schedule_id
          AND bp.start_minute < NEW.end_minute
          AND NEW.start_minute < bp.end_minute
    );
END;

CREATE TRIGGER trg_bell_periods_no_overlap_upd
BEFORE UPDATE OF bell_schedule_id, start_minute, end_minute ON bell_periods
BEGIN
    SELECT RAISE(ABORT, 'Bell period overlaps with existing period in the same schedule')
    WHERE EXISTS (
        SELECT 1 FROM bell_periods bp
        WHERE bp.bell_schedule_id = NEW.bell_schedule_id
          AND bp.id != OLD.id
          AND bp.start_minute < NEW.end_minute
          AND NEW.start_minute < bp.end_minute
    );
END;

BEFORE UPDATE OF bell_schedule_id, period_type, is_schedulable, start_minute, end_minute ON bell_periods

    SELECT RAISE(ABORT, 'Cannot alter timing/type of bell_period referenced by timetable_entry_target_periods')    WHERE EXISTS (

END;

-- 6. Pemetaan Period Jadual Loceng Sasaran
CREATE TRIGGER trg_tetp_validate_ins
BEFORE INSERT ON timetable_entry_target_periods
BEGIN
    SELECT RAISE(ABORT, 'bell_period must be teaching/schedulable, match resolved bell schedule of class/day, match start/end minutes, and fit within entry span')
    WHERE NOT EXISTS (
        SELECT 1
        FROM timetable_entries te
        JOIN timetable_lessons tl ON tl.id = te.timetable_lesson_id AND tl.timetable_version_id = te.timetable_version_id
        JOIN classes c ON c.id = NEW.class_id AND c.session_id = tl.session_id
        JOIN bell_periods bp ON bp.id = NEW.bell_period_id
        WHERE te.id = NEW.timetable_entry_id
          AND te.timetable_version_id = NEW.timetable_version_id
          AND te.timetable_lesson_id = NEW.timetable_lesson_id
          AND bp.period_type = 'teaching'
          AND bp.is_schedulable = 1
          AND bp.start_minute = NEW.start_minute
          AND bp.end_minute = NEW.end_minute
          AND NEW.start_minute >= te.start_minute
          AND NEW.end_minute <= te.end_minute
          AND NEW.period_sequence <= tl.periods_per_lesson
          AND (tl.periods_per_lesson > 1 OR (NEW.start_minute = te.start_minute AND NEW.end_minute = te.end_minute))
          AND bp.bell_schedule_id = COALESCE(
              (SELECT bdo.bell_schedule_id FROM bell_schedule_day_overrides bdo
               WHERE bdo.session_id = c.session_id AND bdo.education_level_id = c.education_level_id AND bdo.day_of_week = te.day_of_week),
              (SELECT bdo.bell_schedule_id FROM bell_schedule_day_overrides bdo
               WHERE bdo.session_id = c.session_id AND bdo.education_level_id IS NULL AND bdo.day_of_week = te.day_of_week),
              (SELECT blm.bell_schedule_id FROM bell_schedule_level_mappings blm
               WHERE blm.session_id = c.session_id AND blm.education_level_id = c.education_level_id),
              (SELECT bs.id FROM bell_schedules bs
               WHERE bs.session_id = c.session_id AND bs.is_default = 1)
          )
    );
    SELECT RAISE(ABORT, 'period_sequence must be strictly contiguous and non-overlapping with existing periods for the target')
    WHERE EXISTS (
        SELECT 1 FROM timetable_entry_target_periods prev
        WHERE prev.timetable_entry_id = NEW.timetable_entry_id
          AND prev.timetable_lesson_target_id = NEW.timetable_lesson_target_id
          AND (
              (prev.period_sequence < NEW.period_sequence AND prev.end_minute > NEW.start_minute)
              OR
              (prev.period_sequence = NEW.period_sequence - 1 AND prev.end_minute != NEW.start_minute)
              OR
              (prev.period_sequence > NEW.period_sequence AND prev.start_minute < NEW.end_minute)
              OR
              (prev.period_sequence = NEW.period_sequence + 1 AND NEW.end_minute != prev.start_minute)
          )
    );
END;

-- 7. Konflik Student Groups & Double-Booking Guru
CREATE TRIGGER trg_te_student_group_conflict_ins
AFTER INSERT ON timetable_entries
BEGIN
    SELECT RAISE(ABORT, 'Student group / class timetable conflict detected (SEMUA, same group, or same subject)')
    WHERE EXISTS (
        SELECT 1
        FROM timetable_lesson_targets t_new
        JOIN timetable_lessons l_new ON l_new.id = NEW.timetable_lesson_id
        JOIN timetable_entries e_old
          ON e_old.timetable_version_id = NEW.timetable_version_id
         AND e_old.day_of_week = NEW.day_of_week
         AND e_old.timetable_lesson_id != NEW.timetable_lesson_id
         AND e_old.start_minute < NEW.end_minute
         AND NEW.start_minute < e_old.end_minute
        JOIN timetable_lesson_targets t_old
          ON t_old.timetable_lesson_id = e_old.timetable_lesson_id
         AND t_old.class_id = t_new.class_id
        JOIN timetable_lessons l_old ON l_old.id = e_old.timetable_lesson_id
        WHERE t_new.timetable_lesson_id = NEW.timetable_lesson_id
          AND (
              t_new.student_group_id IS NULL
              OR t_old.student_group_id IS NULL
              OR t_new.student_group_id = t_old.student_group_id
              OR l_new.subject_id = l_old.subject_id
          )
    );
    SELECT RAISE(ABORT, 'Class exceeds maximum of 2 concurrent student group lessons at the same instant')
    WHERE EXISTS (
        SELECT 1
        FROM timetable_lesson_targets t_new
        JOIN timetable_entries pt
          ON pt.timetable_version_id = NEW.timetable_version_id
         AND pt.day_of_week = NEW.day_of_week
         AND pt.start_minute >= NEW.start_minute
         AND pt.start_minute < NEW.end_minute
        WHERE t_new.timetable_lesson_id = NEW.timetable_lesson_id
          AND (
              SELECT COUNT(DISTINCT e_c.timetable_lesson_id)
              FROM timetable_entries e_c
              JOIN timetable_lesson_targets t_c
                ON t_c.timetable_lesson_id = e_c.timetable_lesson_id
               AND t_c.class_id = t_new.class_id
              WHERE e_c.timetable_version_id = NEW.timetable_version_id
                AND e_c.day_of_week = NEW.day_of_week
                AND e_c.start_minute <= pt.start_minute
                AND pt.start_minute < e_c.end_minute
          ) > 2
    );
    SELECT RAISE(ABORT, 'Teacher double-booking conflict detected across overlapping lessons')
    WHERE EXISTS (
        SELECT 1
        FROM timetable_lesson_teachers lt_new
        JOIN timetable_entries e_old
          ON e_old.timetable_version_id = NEW.timetable_version_id
         AND e_old.day_of_week = NEW.day_of_week
         AND e_old.timetable_lesson_id != NEW.timetable_lesson_id
         AND e_old.start_minute < NEW.end_minute
         AND NEW.start_minute < e_old.end_minute
        JOIN timetable_lesson_teachers lt_old
          ON lt_old.timetable_lesson_id = e_old.timetable_lesson_id
         AND lt_old.teacher_id = lt_new.teacher_id
        WHERE lt_new.timetable_lesson_id = NEW.timetable_lesson_id
    );
END;

         AND tetp.end_minute = NEW.end_minute
        WHERE sra.id = NEW.special_room_allocation_id
          AND NEW.slot_sequence <= sra.periods_used
    );
    SELECT RAISE(ABORT, 'Allocation slot_sequence must be strictly contiguous and non-overlapping')
    WHERE EXISTS (
        SELECT 1 FROM special_room_allocation_slots sib
        WHERE sib.special_room_allocation_id = NEW.special_room_allocation_id
          AND (
              (sib.slot_sequence < NEW.slot_sequence AND sib.end_minute > NEW.start_minute)
              OR
              (sib.slot_sequence = NEW.slot_sequence - 1 AND sib.end_minute != NEW.start_minute)
              OR
              (sib.slot_sequence > NEW.slot_sequence AND sib.start_minute < NEW.end_minute)
              OR
              (sib.slot_sequence = NEW.slot_sequence + 1 AND NEW.end_minute != sib.start_minute)
          )
    );
END;

CREATE TRIGGER trg_sras_validate_upd
BEFORE UPDATE ON special_room_allocation_slots
BEGIN
    SELECT RAISE(ABORT, 'Slot must satisfy slot_sequence <= periods_used and match an actual teaching period of the timetable_entry')
    WHERE NOT EXISTS (
        SELECT 1
        FROM special_room_allocations sra
        JOIN timetable_entry_target_periods tetp
          ON tetp.timetable_entry_id = NEW.timetable_entry_id
         AND tetp.timetable_version_id = NEW.timetable_version_id
         AND tetp.timetable_lesson_id = NEW.timetable_lesson_id
         AND tetp.period_sequence = NEW.slot_sequence
         AND tetp.start_minute = NEW.start_minute
         AND tetp.end_minute = NEW.end_minute
        WHERE sra.id = NEW.special_room_allocation_id
          AND NEW.slot_sequence <= sra.periods_used
    );
    SELECT RAISE(ABORT, 'Allocation slot_sequence must be strictly contiguous and non-overlapping')
    WHERE EXISTS (
        SELECT 1 FROM special_room_allocation_slots sib
        WHERE sib.special_room_allocation_id = NEW.special_room_allocation_id
          AND sib.id != OLD.id
          AND (
              (sib.slot_sequence < NEW.slot_sequence AND sib.end_minute > NEW.start_minute)
              OR
              (sib.slot_sequence = NEW.slot_sequence - 1 AND sib.end_minute != NEW.start_minute)
              OR
              (sib.slot_sequence > NEW.slot_sequence AND sib.start_minute < NEW.end_minute)
              OR
              (sib.slot_sequence = NEW.slot_sequence + 1 AND NEW.end_minute != sib.start_minute)
          )
    );
END;

CREATE TRIGGER trg_sras_max_concurrent_ins
AFTER INSERT ON special_room_allocation_slots
BEGIN
    SELECT RAISE(ABORT, 'Special room max_concurrent_classes exceeded at overlapping slot instant')
    WHERE EXISTS (
        SELECT 1
        FROM rooms r
        JOIN special_room_allocation_slots pt
          ON pt.special_room_schedule_id = NEW.special_room_schedule_id
         AND pt.room_id = NEW.room_id
         AND pt.allocation_date = NEW.allocation_date
         AND pt.start_minute >= NEW.start_minute
         AND pt.start_minute < NEW.end_minute
        WHERE r.id = NEW.room_id
          AND (
              SELECT COUNT(DISTINCT tlt.class_id)
              FROM special_room_allocation_slots s
              JOIN timetable_lesson_targets tlt
                ON tlt.timetable_lesson_id = s.timetable_lesson_id
               AND tlt.timetable_version_id = s.timetable_version_id
              WHERE s.special_room_schedule_id = NEW.special_room_schedule_id
                AND s.room_id = NEW.room_id
                AND s.allocation_date = NEW.allocation_date
                AND s.start_minute <= pt.start_minute
                AND pt.start_minute < s.end_minute
          ) > r.max_concurrent_classes
    );
END;

CREATE TRIGGER trg_sras_max_concurrent_upd
AFTER UPDATE ON special_room_allocation_slots
